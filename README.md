# 방주의 문

노아의 방주 방탈출용 비밀번호 입력 사이트입니다. 참가자는 노아의 가족이 되어, 세상이 물에 잠기기 전(기본 15분) 노아가 남긴 단서로 방주 문의 비밀번호를 풀어야 합니다. 전체 진행자(선장실)가 여러 방의 방 화면을 한 곳에서 관리합니다.

- 사이트: https://jangwonlim.github.io/ark-escape/
- 선장실: 진행자 컴퓨터에서 사이트를 열고 “선장실”을 고릅니다. 게임 내내 이 창을 열어 두세요.
- 방 화면: 방 컴퓨터에서 사이트를 열고 “방 화면”을 고른 뒤 게임 번호와 방 번호를 넣습니다.
- 인트로: 선장실에서 전체 시작을 누르면 모든 방에서 `intro.mp4`(2분 56초)가 동시에 재생되고, 영상이 끝나는 순간 타이머가 시작됩니다. 영상을 바꾸면 `index.html`의 `INTRO_MS`(영상 길이, 밀리초)도 함께 바꾸세요.

선장실과 방 화면은 공개 MQTT 서버 두 곳(EMQX, HiveMQ)을 동시에 거쳐 연결됩니다. 인터넷만 되면 서로 다른 네트워크에서도 작동합니다. 코드는 저장소에 들어가지 않고 게임 때 선장실에서 정합니다.
