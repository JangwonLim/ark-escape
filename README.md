# 방주의 문

노아의 방주 콘셉트 방탈출용 4자리 코드 입력 사이트입니다. 전체 진행자(선장실)가 여러 방의 방 화면을 한 곳에서 관리합니다.

- 사이트: https://jangwonlim.github.io/ark-escape/
- 선장실: 진행자 컴퓨터에서 사이트를 열고 “선장실”을 고릅니다. 게임 내내 이 창을 열어 두세요.
- 방 화면: 방 컴퓨터에서 사이트를 열고 “방 화면”을 고른 뒤 게임 번호와 방 번호를 넣습니다.

선장실과 방 화면은 PeerJS(WebRTC)로 직접 연결되며, 같은 Wi-Fi에서 쓰는 것을 전제로 합니다. 코드는 저장소에 들어가지 않고 게임 때 선장실에서 정합니다.
